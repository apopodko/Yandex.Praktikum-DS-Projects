# Выбор локации для скважины

## Описание проекта
**Заказчик**

Отдел планирования компании «ГлавРосГосНефть»

**Входные данные**

Пробы нефти в трёх регионах с их характеристиками и объемом запасов.

**Задача**

Построение модели для определения региона, с максимальной добычей. Анализ возможной прибыли и рисков.

**Цель**

Определить регион для бурения новой скважины

## Выводы
В результате работы над проектом на основе предоставленных данных по трем регионам были созданы три модели линейной регрессии на каждый регион. Методом bootstrap были расчитаны средняя прибыль с 95% CI и вероятность убытков для добычи в каждом регионе по начальным условиям. Из трех регионов при поставленных условиях для бурения подходит второй регион. Риск убытков - 1% ниже установленного порога в 2.5%, а средняя прибыль - 432 млн. рублей с 95% CI (51.742, 863.042).
