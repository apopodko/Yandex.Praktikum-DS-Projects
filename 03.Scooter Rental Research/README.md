# Статистический анализ данных сервиса проката самокатов GoFast
![image](https://github.com/user-attachments/assets/6005b0af-d1d3-48ad-bb77-41a229e894bf)

## Описание проекта
**Заказчик** - отдел маркетинга сервиса проката самокатов GoFast

**Входные данные** - информация о пользователях, их поездках и подписках из мобильного приложения GoFast

**Задача** - анализ поездок и проверка гипотез

**Цель** - выявить гипотезы, которые могут оказать положительное влияние на развитие бизнеса GoFast

## Выполненные этапы работы
- Загрузка и предварительная обработка данных:
  - Загрузка датасета с информацией о прокате самокатов
  - Обработка пропусков, преобразование типов данных
  - Некоторые выбросы заполнены с помощью линейной регрессии
  - Создание дополнительных признаков


- Анализ данных
  - Изучили активность пользователей по городам и датам
  - Исследовали распределение поездок по времени, расстоянию и продолжительности
  - Оценили вклад разных групп пользователей в общий объём поездок
  - Проверили статистические гипотезы, которые могут быть полезны для развития сервиса
  - Составили рекомендации для отдела маркетинга на основе полученных данных и проверенных гипотез
