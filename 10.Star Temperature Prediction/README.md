# Прогнозирование температуры звезды
![image](https://github.com/user-attachments/assets/8fce7075-a2b2-47b8-b438-8d32e6831101)

## Описание проекта
**Заказчик**
Обсерватория «Небо на ладони»


**Входные данные**
Характеристики изученных 240 звёзд


**Задача**
На основе изученных характиристик 240 звезд создать нейоронную сеть, которая сможет предсказывать температуру на поверхности обнаруженных звезд


**Цель**
Обсерватория хочет внедрить технологии машинного обучения для предсказания температуры звёзд, надеясь, что этот метод будет наиболее точным и удобным

## Выводы
В результате данного исследования на основе данных обсерватории о характеристиках звезд были созданы три модели по предсказанию температуры на поверхности звезды на основе 2-слойных полносвязных нейронных сетей. По указанным требованиям заказчика была отобрана лучшая модель с метрикой RMSE 2703 на тренировочной выборке и 2563 на тестовой выборке.
