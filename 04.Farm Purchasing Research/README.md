# Модель для снижения рисков хозяйства при покупке коров

## Описание проекта
**Заказчик** - фермер, владелец молочного хозяйства «Вольный луг»

**Входные данные** -  данные о стаде фермера на текущий момент и о коровах «ЭкоФермы», которых фермер хочет изучить перед покупкой

**Задача** - определить целевые параметры и входные признаки в данных о стаде фермера. Создать модель линейной регрессии для прогнозирования удоя. Создать модель логистической регрессии для прогнозирования вкуса молока. Оценить коров «ЭкоФермы» с помощью моделей, дать оценку качества и описать модели

**Цель** - разработать модель, которая поможет ему управлять рисками и принимать объективное решение о покупке

## Выполненные этапы работы
- Загрузка и предварительная обработка данных:
  - Загрузка датасета с информацией о прокате самокатов
  - Обработка пропусков, преобразование типов данных
  - Некоторые выбросы заполнены с помощью линейной регрессии
  - Создание дополнительных признаков


- Анализ данных
  - Изучили активность пользователей по городам и датам
  - Исследовали распределение поездок по времени, расстоянию и продолжительности
  - Оценили вклад разных групп пользователей в общий объём поездок
  - Проверили статистические гипотезы, которые могут быть полезны для развития сервиса
  - Составили рекомендации для отдела маркетинга на основе полученных данных и проверенных гипотез
