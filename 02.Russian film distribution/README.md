# Исследование данных о российском кинопрокате
![image](https://github.com/user-attachments/assets/65bb7ab1-5f1e-4a43-9516-613a0d973cf9)

## Описание проекта
**Заказчик** - Министерство культуры Российской Федерации

**Входные данные** - прокатные удостоверения, информация о сборах и господдержке фильмов, опубликованные на портале открытых данных Министерства культуры. Рейтинг и жанр фильма с сайта КиноПоиск.

**Задача** - изучить рынок российского кинопроката и выявить текущие тренды

**Цель** - определить, какие фильмы интересны зрител

## Выполненные этапы работы
- Загрузка и предварительная обработка данных:
  - Загрузка датасета с информацией о фильмах, выпущенных в прокат в России
  - Обработка пропусков, преобразование типов данных
  - Очистка данных от выбросов


- Анализ данных
  - Исследованы количественные характеристики проката: количество фильмов, их кассовые сборы
  - Определены самые прибыльные жанры фильмов
  - Проанализированы возрастные ограничения фильмов и их влияние на сборы
  - Проведено сравнение по годам: как менялось количество выпускаемых фильмов и общий доход
  - Построены графики для лучшего восприятия тенденций (жанры, год выпуска, сборы)
  - Представлены выводы о наиболее популярных категориях фильмов в российском прокате
  - Определены жанры-лидеры по кассовым сборам
  - Сделаны выводы о предпочтениях аудитории и тенденциях изменения рынка кинопроката в России
