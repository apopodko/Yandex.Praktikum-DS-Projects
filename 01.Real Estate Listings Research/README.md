# Исследование объявлений о продаже квартир

## Описание проекта
**Заказчик** - отдел аналитики

**Входные данные** - архив объявлений о продаже квартир в Санкт-Петербурге и соседних населённых пунктах за несколько лет из сервиса Яндекс Недвижимость

**Задача** - научиться определять рыночную стоимость объектов недвижимости с использованием исследовательского анализа данных. Определение параметров, влияющих на цену объектов

**Цель** - построение автоматизированной системы для отслеживания аномалий и мошеннической деятельности

## Выполненные этапы работы
- Загрузка и предварительная обработка данных:
  - Загрузка датасета
  - Проверка данных на пропуски и их обработка
  - Приведение типов данных к корректному формату
  - Очистка данных от выбросов


- Анализ данных
  - Анализ распределения признаков
  - Выявление выбросов и аномалий
  - Заполнение пропусков локаций с помощью geopy
  - Построение графиков распределения
  - Построение корреляционной матрицы для определения взаимосвязей между признаками
  - Определены наиболее важные характеристики, влияющие на цену недвижимости
  - Сделаны выводы о качестве данных и их пригодности для дальнейшего моделирования
