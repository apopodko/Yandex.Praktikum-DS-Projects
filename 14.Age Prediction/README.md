# Определение возраста покупателей по фотографии
![image](https://github.com/user-attachments/assets/81f225c4-d7c6-4410-acef-37ef2e97a295)

## Описание проекта
**Заказчик**

Сетевой супермаркет «Хлеб-Соль»


**Входные данные**

Пул фотографий покупателей разных возрастов и таблица соответствия возраста и фотографии


**Задача**

Провести анализ данных и построить модель, которая по фотографии определит приблизительный возраст человека


**Цель**

Анализировать покупки и предлагать товары, которые могут заинтересовать покупателей этой возрастной группы. Контролировать добросовестность кассиров при продаже алкоголя

## Выводы
В рамках проекта была создана модель определения возраста покупателей на основе сверточной нейросети InceptionResNetV2, которая показала метрику MAE 5.463 на валидации, что с запасом превосходит необходимую метрику по условию заказчика (В статье о датасете,  с которым вы работаете, значение MAE равно 5.4 — если вы получите MAE меньше 7, это будет отличный результат!). Обучающая выборка была предоставлена заказчиком.
